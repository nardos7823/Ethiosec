# 🛡️ EthioSec — Cybersecurity Portfolio & Toolkit

A modern, responsive cybersecurity portfolio and interactive toolkit built with **Python (Flask)**, **HTML5**, and **CSS3**. 

Designed to showcase offensive and defensive security concepts, ethical hacking projects, and educational resources.

---

## ✨ Features

* **🎥 Global Dynamic Background:** Implements a seamless, full-page background video (`hero.mp4`) fixed to the viewport with a high-contrast dark overlay.
* **🔍 Local TCP Port Scanner:** A Flask-powered backend utility allowing safe, authorized scanning of `127.0.0.1` for open TCP ports and active services.
* **🔑 Real-Time Password Strength Checker:** Client-side JavaScript tool that evaluates password complexity, length, and character variation instantly.
* **🎣 Phishing Awareness Quiz:** Interactive training module helping users identify malicious emails and common social engineering red flags.
* **📚 Curated Learning Hub:** Resource center featuring recommended free courses and labs across cybersecurity, web development, aerospace engineering, emerging technologies, and embedded systems.

---

## 🚀 Tech Stack

* **Backend:** Python, Flask, Flask-WTF (CSRF Protection)
* **Frontend:** HTML5, CSS3, Vanilla JavaScript
* **Styling:** Custom CSS with glassmorphism effects and fully responsive layouts for mobile and desktop.
